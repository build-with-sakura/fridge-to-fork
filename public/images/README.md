## Photo rules

- Use only photos you own or have a licence to use.
- Landscape shape works best. About 1200 x 800 pixels is plenty.
- Keep each file under about 300 KB so the app loads fast.
- Add the photographer or licence note to `imageCredit` in `src/data/recipes.js`.

Until a photo is added, the app shows the drawn dish instead.
